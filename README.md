# Waad Events

Premium Arabic-first React/Vite website for Waad Events.

## Run

```powershell
npm.cmd install
npm.cmd run dev
```

Website: `http://localhost:5173/`

Admin: `http://localhost:5173/admin`

## Main structure

- `src/components/Hero.jsx` — cinematic full-screen hero
- `src/components/Loader.jsx` — startup loader
- `src/components/CategoryShowcase.jsx` — categories
- `src/components/SelectedWork.jsx` — selected work
- `src/pages/AdminDashboard.jsx` — Arabic content editor
- `src/data/siteData.js` — default content

Hero text and buttons are real HTML/CSS elements, not part of the hero artwork.
